# Pratham Patel — Developer Portfolio

A responsive, light minimalist portfolio built with React, Vite, React Bootstrap, React Router, and custom CSS.

## Features
- Responsive navigation and section layout
- About, skills, projects, education, and contact sections
- Project search and category filters
- Contact form validation that opens the visitor's email app with a prefilled message
- React Router contact page
- Custom responsive styling

## Run locally

Make sure Node.js and npm are installed.

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal (usually `http://localhost:5173`).

## Customize
- Update project information in `src/App.jsx` in the `projects` array.
- Add real GitHub repository or live demo URLs in each project's `link` property.
- Update skills and education in the `skills` array and `Education` component.
- Update contact links and email in `src/App.jsx` if they change.

## Note
Project descriptions are based on the project titles supplied and are intentionally general. Replace them with the exact features you built. The contact form uses `mailto:` and does not send messages to a server.
